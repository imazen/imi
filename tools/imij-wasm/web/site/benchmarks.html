Browser decode of real 4K and 8K photographs

4K & 8K decode in your browser

Each run downloads hash-pinned files and decodes them on this device. IMI files decode in WebAssembly SIMD workers; the headline column is 8 IMI workers. Other formats use the browser's own decoder (createImageBitmap), which picks its own threads. Download time is reported separately from decode time.

    The preview shows the last trial of the most recent decode, scaled down. Drawing it happens after the decode timer stops. Each decoder first decodes the file once untimed, so compilation and warm-up in a fresh worker pool are not counted; the timed trials follow. IMI decode time covers input copy, index open, range transfer to workers, decoding and the final RGBA bitmap; worker start-up and hash verification are outside it. Native decode time covers createImageBitmap until the bitmap is ready.
